# Eksperymenty AINUMPSA

Wczesne eksperymenty artystyczno-filozoficzne. Wizualizacje ASCII, symulacje QRNG, analizy statystyczne. Nie są częścią pipeline'u produkcyjnego — dokumentują drogę myślową projektu.

- `action_scan_matrix.yml` — workflow skanu macierzy
- `algorytm_zasysania_uwagi.py` — eksperyment uwagi
- `algorytm_siewu.py` — sonda siewna pola Tensor T
- `algorytm_zbioru.py` — sonda zbierająca 5000 bitów
- `data_analysis.py` — analiza chi-kwadrat
- `import_eksport_data.py` — symulacja roju (Most ER)
- `nuclear_information.py` — fala uderzeniowa ASCII
